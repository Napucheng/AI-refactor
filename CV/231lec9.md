## Feature Visualization & Inversion

visualizing the neural network

| 类别     | 模型 / 方法                                                  | 核心意义                                                     |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 奠基性   | **Zeiler-Fergus Visualization (2014)**                       | 用反卷积可视化 CNN 特征，首次让人类看懂神经网络 “看” 到了什么 |
| 促进发展 | **Grad-CAM (2016)**                                          | 基于梯度生成类别激活图，轻量化、可解释性强，广泛用于模型诊断 |
| 最前沿   | **CLIP-Dissect (2022)** / **Inversion with Diffusion (2023)** | 结合大模型与扩散模型，实现更细粒度特征反演与可视化           |

## Adversarial Examples

| 类别     | 方法 / 模型                                              | 核心意义                                                     |
| -------- | -------------------------------------------------------- | ------------------------------------------------------------ |
| 奠基性   | **FGSM (2014)**                                          | 首次提出基于梯度的对抗攻击，揭示深度学习易受微小扰动的脆弱性 |
| 促进发展 | **PGD (2017)** / **DeepFool (2016)**                     | PGD 成为最强大的一阶攻击基准；DeepFool 用于最小扰动分析      |
| 最前沿   | **AutoAttack (2020)** / **Adversarial Diffusion (2023)** | 自动化组合攻击评估模型鲁棒性；基于扩散模型生成更隐蔽对抗样本 |

## Style Transfer

| 类别     | 模型                                                         | 核心意义                                               |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------ |
| 奠基性   | **Gatys Neural Style Transfer (2015)**                       | 基于 VGG19，首次实现内容与风格分离的神经风格迁移       |
| 促进发展 | **CycleGAN (2017)**                                          | 无配对图像风格迁移，打破数据配对限制，应用场景大幅拓展 |
| 最前沿   | **StyleGAN-XL (2023)** / **Diffusion Style Transfer (2023)** | 高保真、高分辨率风格迁移；扩散模型实现更灵活的风格编辑 |
